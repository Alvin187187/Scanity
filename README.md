# NutriGuard

NutriGuard is an AI-powered food safety and nutrition decision support system that helps consumers determine whether packaged foods are safe based on their allergies, dietary restrictions, and health conditions. Using barcode scanning, OCR, and personalized health profiling, it provides nutrition evaluations and personalized recommendations.

## Features

- Barcode/QR Code Scanner
- OCR-Based Food Label Scanner
- Personalized Health Profile
- Allergy Detection
- Ingredient Translator
- Nutrition Score Evaluation
- AI-Powered Health Explanations
- Product Comparison

## Objectives

- Help consumers understand food labels and ingredients.
- Detect allergens and health risks based on personalized profiles.
- Simplify complex nutrition and ingredient information.
- Support informed and healthier food purchasing decisions.
