# Code of conduct

Scanity is a closed repository. Outside participation is not allowed.

## Access

- Contributors are not allowed.
- Do not clone, fork, download, copy, or otherwise take this repository or any file in it.
- Do not open issues, pull requests, discussions, or any other contribution.
- Only the repository owners have the right to access this repository, change it, and keep its files.

## Owners

People who already have owner access treat one another with respect in the private spaces they use for this project. Harassment, insults, and publishing another person's private information are not acceptable.

Report a problem with another owner privately to [@Alvin187187](https://github.com/Alvin187187). Do not turn that report into a public issue.
